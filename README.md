# FlyRank Frontend AI Engineering — Capstone

Starter repo for the FlyRank Frontend AI Engineering track.

This repository does not contain an application yet. There is no `package.json` or source tree. Stack and coding rules live in `CLAUDE.md`.

## Stack (intended)

- React
- TypeScript
- Vite
- Node.js (LTS)

## Prerequisites

- [Node.js LTS](https://nodejs.org/)
- Git

## Setup

```bash
git clone https://github.com/rehab860/capstone-project.git
cd capstone-project
```

After a Vite + React + TypeScript app is added, install and run it with the scripts from that `package.json`. Those commands are not available yet.

## Conventions

- camelCase for variables and functions
- PascalCase for React components
- 2-space indentation
- Conventional Commits: `feat:`, `fix:`, `docs:`, `chore:`, `refactor:`, `test:`
- Small, focused commits
